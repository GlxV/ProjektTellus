## Como usar

- Comece por **`RESUMO_PARA_O_PROFESSOR.md`** (leitura rápida).
- Leia **`PROCESSO_E_METODOLOGIA.md`** para entender a estratégia de prompts, iteração, agentes e validação.
- Os arquivos de **`prompts/`** descrevem as oito principais rodadas. O original inicial está preservado integralmente; as demais são **reconstruções documentais**, não transcrições literais autenticadas.
- **`EVIDENCIAS_E_LIMITES.md`** mostra quais resultados são documentados e quais não estão certificados.
- Os dois arquivos de `fontes/` foram copiados do ZIP de documentação fornecido, para consulta de contexto.

## Nota essencial de proveniência

**Somente `prompts/01_SOL_BRIEF_ORIGINAL.md` é uma cópia integral de um arquivo original de prompt encontrado em `docs/BRIEF_SOL.md`.** Os outros arquivos da pasta `prompts/` foram compilados a partir dos pedidos e respostas da conversa e dos relatórios do projeto. Eles são úteis para estudar a estrutura da instrução, mas **não devem ser exibidos como logs literais do texto enviado aos agentes**. No caso de Luna, a versão literal não foi recuperada.

Os próprios prompts foram estruturados com auxílio do ChatGPT, e as implementações e auditorias relatadas foram realizadas por outros modelos/agentes. Não sugerir autoria manual integral do código. O professor poderá examinar os códigos Java e pedir justificativas.

Este arquivo é uma documentação acadêmica retrospectiva, não uma certificação independente da qualidade de todo o software.
